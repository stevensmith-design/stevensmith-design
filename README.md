# Steven Smith

I'm a bilingual (English and Japanese) AI product manager in Tokyo. I use agentic practices to strategise, design, build and deploy digital products that run in production. This year that included a production iOS app for an enterprise client, which I delivered as the sole designer and front-end developer using agent tooling I built.

Alongside that I build automations, workflows and tools, some for my own daily work and some for other people and teams to use. Underneath most of them is the same idea: an agent harness that holds a project to its own standards, so AI-assisted work ends up shippable rather than just looking finished.

## What's here

These are tools I use in my own work, made public so you can see how I work and use them if they help.

- **[AIspy](https://github.com/stevensmith-design/aispy)**: a second pair of eyes for your UX, UI and IA. Reviews a live site or app and gives you a report, an IA analysis and a before-and-after mock.
- **[OccupAI](https://github.com/stevensmith-design/occupai)**: a daily security check-in for people who build with AI, run by your own AI agent.
- **[Agentic Design Kit](https://github.com/stevensmith-design/agentic-design-kit)**: eleven skills that help an AI agent design better.
- **[Agentic Design Harness](https://github.com/stevensmith-design/agentic-design-harness)**: turns the design kit into an always-on design environment.
- **[Agent Harness](https://github.com/stevensmith-design/agent-harness)**: a ready-made harness for building software with AI, and a kit that builds one around any kind of work.
- **[Image Prompt Engineer](https://github.com/stevensmith-design/image-prompt-engineer)**: high-quality AI images, without learning how to write prompts.
